# What's Wrong With Science?

Course website for **BIOL-UA 800: What's Wrong With Science?**
NYU Department of Biology — Fall 2026

**Live site:** https://davidgresham.github.io/whatswrongwithscience

## About

A single-page static website for a 1-credit pass/fail undergraduate course exploring how science works in society — from funding and publishing to politics, public trust, and the future. Seven weekly sessions (Sept 9 – Oct 21, 2026, Wednesdays 6–7:30 PM, Cantor Film Center 101) featuring a lecture, in-class activities, and Q&A with a distinguished guest speaker.

Instructor: [David Gresham](https://greshamlab.bio.nyu.edu), Professor of Biology, NYU

## Structure

```
index.html        — single-page site
css/style.css     — all styles
pdfs/             — session slide decks (Introduction + Sessions 1–7)
images/           — speaker headshots
```

## Custom Domain

To point a custom domain (e.g. `whatswrongwithscience.org`) to this site:
1. Add a `CNAME` file containing the domain name
2. Configure DNS A records to GitHub Pages IPs
3. Enable the custom domain in repo Settings → Pages
